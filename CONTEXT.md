# Companion context

The terms in this glossary distinguish conversation, evidence and authority.
The target contract is in [Companion context design](docs/companion-context-design.md).

| Term | Meaning |
|---|---|
| Companion | An agent that participates in a relationship or shared conversation without making every interaction a task. |
| Event | An occurrence that the companion can observe, such as a message, a reaction or a scheduled opportunity. |
| Admission | Permission to consider an event. Admission does not require a public response. |
| Turn | One admitted event and the agent's bounded opportunity to respond or act. |
| Observation | Attributed evidence about a situation. An observation is not an instruction, permission or established memory. |
| Audience | The people entitled to receive a fact in a particular conversation. Knowing a fact does not make every audience entitled to it. |
| Memory fact | A retained assertion with a subject, source, audience and correction history. A quotation or roleplay event is not automatically a fact about a person. |
| Response disposition | The decision to speak, act, react or remain silent. |
| Delivery outcome | What the audience actually received, including an intentional absence of output or a delivery failure. It can differ from the model's draft. |
| Continuity | Accurate reuse of relevant prior interaction, including boundaries, corrections and unfinished commitments. It is not repetition of all prior context. |
| Improvement proposal | An evidence-backed suggestion to change behavior or procedure. It does not authorize its own adoption. |
